## What it does

Plays opposing counsel's expert before opposing counsel does. Reads a damages analysis assumption by assumption and produces the cross-examination it will face — so the weaknesses get fixed or defended in the report, not discovered in deposition.

## Inputs

- The damages analysis: model, assumptions, methodology narrative
- Case context: claim type (lost profits, diminution, personal), jurisdiction, the professional testifying
- CN's past experience `[EXTRACT: which challenges CN's work has actually faced — Daubert-type methodology attacks, causation gaps, mitigation arguments]`

## Process

1. Inventory every assumption: growth rates, but-for scenarios, discount rates, cost structures, causation links, mitigation treatment, period selection.
2. Attack each from the standard playbook — v0.1 generic adversary: speculative but-for world · causation vs. correlation · failure to mitigate · alternative-cause exclusion · benchmark cherry-picking · discount-rate mismatch · pre-existing trend ignored · damages period unsupported `[EXTRACT: CN's ranked list of what actually gets attacked in their jurisdiction and case mix]`.
3. Score each attack: strength of the challenge, quality of the current defense, fix available.
4. Draft the cross-exam questions the testifying professional will face, with the honest answers — or the flag that no good answer exists yet.
5. Recommend: fix the assumption, add the support, or prepare the defense — per item.

## Output

A stress-test memo: assumption inventory · attack-by-attack assessment (challenge / current defense / recommendation) · mock cross-exam question set · the "if we can only fix three things" list. Internal work product, never produced.

## Guardrails

- Adversarial honesty is the job: a soft stress-test is worthless. The memo says "this assumption will not survive" when it won't.
- Work-product discipline: labeled privileged/internal `[EXTRACT: how CN handles work-product labeling with counsel]`; never filed to client-visible folders.
- The skill critiques analysis; it never fabricates support. Missing support is reported as missing.
